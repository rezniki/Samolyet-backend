# Samolyet Backend (MVP)

Backend для приложения знакомств без свайпов.

## Структура
- `src/controllers/` — обработчики запросов
- `src/services/` — бизнес-логика
- `src/models/` — Mongoose схемы
- `src/routes/` — API роуты
- `src/middleware/` — middleware функции

## Запуск (разработка)
```bash
npm install
cp .env.example .env  # заполнить переменные
npm run dev
```
